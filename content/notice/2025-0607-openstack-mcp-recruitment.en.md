The **OpenInfra Korea User Group** is recruiting members to join the **Openstack MCP Project**.  
By integrating the Openstack API with the Model Context Protocol (MCP), we aim to create a new paradigm for cloud resource management!

## Project Overview

- **Project Name**: Openstack MCP Server  
- **Description**: An open-source project that combines Openstack resource management, monitoring, and workflow automation with Large Language Models (LLMs) to make cloud operations more intuitive and efficient.  
- **Technical Keywords**: Openstack API, Model Context Protocol (MCP), LLM (Large Language Model), Cloud Automation  

## Recruitment Details

- **Number of Participants**: 4  
- **Application Period**: June 7 (Sat) – June 16 (Mon), 2025, 23:59 KST  
- **Result Announcement**: June 17 (Tue), 2025 — via email submitted with the application  
- **Project Duration**: 12 weeks (expected to end by September)  
- **Participation Fee**: Free  
- **Location**: To be announced
