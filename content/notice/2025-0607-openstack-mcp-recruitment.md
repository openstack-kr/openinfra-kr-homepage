OpenInfra Korea User Group에서 **Openstack MCP 프로젝트**에 함께할 인원을 모집합니다.  
Openstack API와 Model Context Protocol(MCP)를 통합하여 클라우드 자원 관리의 새로운 패러다임을 함께 만들어봅시다!

## 프로젝트 소개

- **프로젝트명**: Openstack MCP Server  
- **내용**: Openstack 환경에서의 자원 관리, 모니터링 및 워크플로우 자동화를 대규모 언어 모델과 결합해 직관적이고 효율적으로 만드는 오픈소스 프로젝트입니다.  
- **기술 키워드**: Openstack API, Model Context Protocol(MCP), LLM(대규모 언어 모델), 클라우드 자동화  

## 모집 개요

- **모집 인원**: 4명  
- **모집 기간**: 2025년 6월 7일(토) ~ 6월 16일(월) 23시 59분

- **참여 비용**: 없음
